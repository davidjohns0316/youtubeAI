Connect YouTube
Setup instructions
  1. Go to console.cloud.google.com
  2. Create a project → Enable YouTube Data API v3
  3. Create OAuth 2.0 credentials (Web application type)
  4. Add authorized redirect URI:
    http://localhost:8000/api/auth/youtube/callback
  5. Download JSON → save as credentials/youtube_client_secrets.json
  6. Click Connect YouTube above

Checking...
Connect TikTok
Setup instructions
  1. Apply at developers.tiktok.com
  2. Create an app → request video.upload and video.publish scopes
  3. Add redirect URI: http://localhost:8000/api/auth/tiktok/callback
  4. Copy your Client Key and Secret into .env
  5. Restart the app, then click Connect TikTok
⚠ TikTok API access requires business account approval and can take several weeks.
